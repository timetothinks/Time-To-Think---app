◆ changeScreenPending()

void ScreenManager::changeScreenPending ( )

Cambia de pantalla remplazando la actual por ScreenManager::nextScreenName.

Esta funcion esta hecha para evitar problemas de memoria en general limpia la memoria de la anterior pantalla para introducir una nueva de forma limpia

Primero es necesario usar ScreenManager::changeScreen() para validar la nueva pantalla
