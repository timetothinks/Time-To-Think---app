# Historial de cambios

Todos los cambios importantes de Time to Think se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es/1.1.0/) y el proyecto sigue el versionado semántico (Semantic Versioning).

## [0.1.0-beta] - 2026-11-16

### Añadido
- Primera versión beta pública de Time to Think.
- Aplicación educativa desarrollada en C++ utilizando raylib.
- Interfaz gráfica interactiva.
- Sistema inicial de gestión de lecciones.
- Componentes de interfaz reutilizables.
- Documentación del código fuente mediante Doxygen.
- Configuración de compilación mediante CMake.

### Notas
- Esta es una versión beta inicial.
- Las funcionalidades y la arquitectura interna pueden cambiar en futuras versiones.
- Se planean mejoras e implemenaciones amplias del contenido educativo.
