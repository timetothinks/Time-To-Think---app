# Time to think
## descripción
Time to think, es un software eduativo creado para ser una herramienta de apoyo para docentes dentro de la educación media superior en México

## acerca de
Este proyecto esta especialmente dedicado para docentes, pero tambien puede ser usado por estudiantes de forma autonoma.

Su propósito es ofrecer una herramienta educativa que apoye los procesos de enseñanza y aprendizaje.
